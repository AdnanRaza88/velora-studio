# Textile repeat systems (production)

## Block (straight / full-drop)
Tile at (c*W, r*H). Fastest. Best for geometric, checks, small ditsy.

## Half-brick
Row r offset by (r % 2) * (W/2). Horizontal rhythm. Apparel, upholstery.

## Half-drop
Column c offset by (c % 2) * (H/2). Most common apparel floral. Diagonal flow hides seams.

## Mirror
Reflect tile on X and/or Y to form 2W×2H unit. Mathematically seamless without inpaint. Damask, formal.

## Seam test
After tiling, edges must match: T[H-1,x] aligns with T[0,x] (or offset partner for brick/drop). Motif should not sit on the cut unless intentional.

## Color jobs
Figure (motif), ground (field), accent (highlight). Limited ink sets for print (1–6 colors typical for rotary).
